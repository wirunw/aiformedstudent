# AI for Health Students

เว็บประกอบการสอน AI สำหรับนักศึกษาแพทย์ เภสัช และพยาบาล โดย ดร.ภก.วิรุณ เวชศิริ

- `index.html` Prompt Lab: คลัง prompt ปรับเงื่อนไขได้ 15 งาน
- `workshop.html` Workflow Lab: งานกลุ่ม 8 workflow สำหรับฝึกแตกงานเป็น task และ prompt
